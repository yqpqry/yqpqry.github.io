# Qingmao Yao Academic Homepage

This is Qingmao Yao's academic homepage, built with the Academic Pages Jekyll template.

## Main Content

* Homepage: `_pages/about.md`
* Publications page: `_pages/publications.html`
* CV page: `_pages/cv.md`
* Publication entries: `_publications/`
* Site configuration: `_config.yml`
* Navigation: `_data/navigation.yml`

## Before Publishing

Update these fields in `_config.yml` after creating the GitHub repository:

```yaml
url: "https://your-github-username.github.io"
repository: "your-github-username/your-github-username.github.io"
```

If you add a profile photo later, place it in `images/` and set:

```yaml
author:
  avatar: "your-photo.jpg"
```
